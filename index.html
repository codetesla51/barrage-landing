What you get
auto-ramp
Doubles concurrency until a layer breaks, then fine-fills to pin the exact level — and names which runner caused the break.
capacity finder
Maps buckets to active users and reports where it starts straining, instead of handing you a number to interpret.
compare & CI gate
Diff two JSON runs, exit non-zero when a P99 crosses budget. A regression fails the pipeline before it ships.
scenario mode
Weighted user journeys with per-virtual-user token extraction and {{var}} interpolation across steps.
masked spikes
Storage spiked but HTTP held? Still flagged. That's the bottleneck you find before your users do.
